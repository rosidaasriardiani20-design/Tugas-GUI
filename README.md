Nama: Rosida Asri Ardiani

## Deskripsi

Aplikasi ini dibuat menggunakan Java Swing untuk menampilkan pilihan hari dari Senin sampai Sabtu. Pengguna dapat memilih hari dengan menekan salah satu tombol yang tersedia. Setelah tombol ditekan, nama hari yang dipilih akan ditampilkan pada bagian bawah aplikasi.

Komponen GUI yang Digunakan

1. Top-Level Container Class
   
   - JFrame, digunakan sebagai jendela utama aplikasi.

2. Intermediate Container Class
   
   - JPanel, digunakan untuk membagi tampilan menjadi beberapa bagian.

3. Atomic Component Class
   
   - JLabel, digunakan untuk menampilkan judul dan hasil pilihan.
   - JButton, digunakan sebagai tombol pilihan hari.

4. Layout Classes
   
   - BorderLayout, FlowLayout, dan GridLayout.

5. Event Listener
   
   - ActionListener, digunakan untuk menangani klik tombol.
   - actionPerformed(), digunakan untuk memproses pilihan hari.

Cara Menjalankan

1. Buka project menggunakan Visual Studio Code.
2. Buka file PemilihanHari.java.
3. Jalankan program.
